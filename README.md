# ห้องคุย Claude × Gemini — ทีมทำคลิปช่อง @pora7307

ห้องนี้คือที่ให้เดชา (Claude) กับ Gemini ปรึกษากันและส่งงานกัน โดยมีเจ้าของช่องเป็นคนกลาง ทำตามแบบ repo yingad-links ที่เคยใช้กับมานะ (Grok) แต่เปลี่ยนคู่คุยเป็น Gemini

## ข้อจำกัดที่ต้องรู้

แอป Gemini แบบฟรีเขียนลง GitHub เองไม่ได้ เจ้าของช่องจึงต้องคัดลอกข้อความระหว่างสองฝั่งเอง ส่วนเดชาอ่านและเขียนไฟล์ในห้องนี้ได้เมื่อ repo นี้อยู่ในสิทธิ์ GitHub ของเซสชัน

## วิธีใช้ทุกวัน

1. เดชาเขียนข้อความหรือใบสั่งงานใหม่ลง `claude-to-gemini.md` (ใหม่สุดอยู่บนสุด) และเก็บใบสั่งงานเต็มไว้ใน `work-orders/`
2. เจ้าของช่องคัดลอกข้อความนั้นไปวางในแอป Gemini หรืออัปโหลดไฟล์ใน `work-orders/` ให้ Gemini
3. เจ้าของช่องคัดลอกคำตอบของ Gemini มาวางใน `gemini-to-claude.md` (ใหม่สุดอยู่บนสุด) แล้วบอกเดชา
4. เดชาอ่านแล้วตอบต่อ แก้ใบสั่งงาน หรือส่งงานถัดไป

## ไฟล์ในห้อง

| ไฟล์ | ใช้ทำอะไร | ใครเขียน |
|---|---|---|
| `guide.md` | กติกาทีมและรูปแบบใบสั่งงาน | เจ้าของช่อง / เดชา |
| `claude-to-gemini.md` | ข้อความจากเดชาถึง Gemini | เดชา |
| `gemini-to-claude.md` | ข้อความจาก Gemini ถึงเดชา | เจ้าของช่องวางให้ |
| `to-team.md` | คำสั่งด่วนจากเจ้าของช่อง ทั้งสองฝั่งอ่านอย่างเดียว | เจ้าของช่อง |
| `work-orders/` | ใบสั่งงานเต็มของแต่ละคลิป ตั้งชื่อตามรหัสคลิป | เดชา |

## ข้อห้ามของห้องนี้

- ห้ามใส่รหัสลับ คีย์ API หรือรหัสผ่านในไฟล์ใดๆ
- ห้ามยุ่งกับระบบบัญชีและการแจ้งเตือนของระบบ
- ห้ามลบโพสต์ และห้ามโพสต์เอง การโพสต์เป็นหน้าที่ของเจ้าของช่อง
- Gemini ไม่แต่งเนื้อหาเพิ่มเอง ถ้าทำฉากไหนไม่ได้ให้บอกเลขฉากพร้อมเหตุผล
